# 心流日程 MindFlow（微信小程序 MVP）

打开即打卡，顺手练大脑。包含：今日首页（时间轴 + 打卡 + 进度环 + 连击）、一句话自然语言添加日程、月历日程视图、数据统计、习惯管理（首页可直接增改）、四种脑力训练（数字/图案/颜色舒尔特 + 数字降序速点）。

所有数据仅保存在本机 Storage，不依赖服务器与云开发。

## 运行前准备

1. 安装最新版「微信开发者工具」。
2. 用注册小程序的微信扫码登录。
3. 把 `project.config.json` 里的 `appid` 替换成你的小程序 AppID（`wxa220bf792ba1fbce`）。
4. 语音功能当前未启用，暂不需要添加任何插件。

## 导入与预览

1. 开发者工具 → 导入项目 → 选择本目录（含 `app.json` 的根目录）。
2. 点「编译」即可运行；点「预览」用手机微信扫码真机体验。

## 当前功能说明

- 行程全局唯一：今日时间轴、日程月视图、周视图与各新增/编辑入口共享同一份行程数据，任意一处增改删都会自动同步到其它板块；「我的习惯」为独立数据，不参与行程同步。
- 智能添加：输入「明天下午三点开会」这类句子，自动解析日期与时间，可预览后保存。
- 打卡：一键完成，连击不断档；打卡位置有轻量庆祝动画，无震动打扰。
- 习惯：首页即可新建、重命名、删除习惯，并直接打卡。
- 待办：首页新增「待办」模块，与时间轴同套视觉，勾选完成即置灰划线。
- 今日时间轴：卡片次序为 色块 → 语义图标 → 名称 → 时间；相邻卡片色块颜色不相同且只用明亮色。
- 专注：正计时 / 番茄钟 / 倒计时，番茄钟可切换小猫钟等形象钟，环形计时支持开始/暂停/继续。
- 周视图：周一至周日时间轴网格，课程卡跨时段延伸、带状态与地点。
- 日历：月视图 + 日期格内彩色分类标签与日程文本 + 点选查看/操作。
- 训练：舒尔特含数字（3/4/5×5）、图案（3/4×4）、颜色（3×3）三种玩法，开始前有玩法说明与 3 秒倒计时；另有「数字降序速点」：从 50 点回 1，屏幕固定显示 5 个降序数字，点一次自动补位并整体刷新位置。
- 我的：可设置昵称、本地头像；支持「导入数据」：粘贴文字或选择 CSV/文本，识别“周几 + 时间 + 内容”，按每周循环或仅一次批量加入日程。
- 分享：首页可转发，为裂变预留。
- 视觉：底部 Tab 为「今日 / 日程 / 周视图 / 专注 / 我的」，图标以毛绒针织质感的自由轮廓呈现（无几何框），「我的」为圆+半圆人像；卡片统一动态毛玻璃与大圆角。

## 已知边界（MVP）

- 语音指令暂未开放，后续版本再接入（届时需在公众平台添加「微信同声传译」插件）。
- 头像读取相册时，微信/系统会弹出照片授权（可选手动选择的部分照片或所有照片）；拒绝授权时应用内会引导去设置。
- 数据仅存本机，无云同步、无订阅消息提醒、无登录（P1 计划）。
- 导入暂不支持直接解析 .xlsx 与图片识别；Excel 请另存为 CSV，图片中的课表请用文字粘贴。

## 迭代建议（P1）

1. 恢复语音添加，并接入微信云开发（登录、跨设备同步、订阅消息提醒）。
2. 补齐 N-Back / Stroop / 华容道 / 序列记忆等训练，以及分享卡片自动生成。
